# 작업 하네스 — AI Team Kit (제품: 렉시오 / 가제)

세션을 시작할 때 **가장 먼저** 읽는 문서다. 사람이 읽는 소개서가 아니라 작업
전에 대조하는 기준이다 — 코드를 고치기 전에 여기 규칙을 확인하고, 고친 뒤에는
"지금 상태"를 갱신한다. **문서가 코드보다 앞서 있으면 거짓말이다.**

이 문서는 세션 부트스트랩용이라 **짧게 유지한다.** 전체 구현 이력·화면별 설계
메모 같은 깊은 맥락은 담지 않는다 — 기능별 문서와 `git log`, 아래 "더 볼 것"을
따라간다. 낡을 값(최신 커밋 해시 등)은 박아두지 않는다.

| 날짜 (렉시오) | 기록용 하루(로컬 04:00 경계)와 전례일(실제 날짜)은 **다른 함수로 계산한다** — `todayForRecord()` / `todayForLiturgy()` (PRD §7-A) | 00:00~04:00 구간에서 기록 날짜와 전례일이 어긋나 "어제 것을 오늘로 세는" 버그가 난다 |
| (예시) 기능 게이트 | 등급을 직접 비교하지 않고 기능 카탈로그의 키로 검사 | 요금제가 바뀔 때 호출부를 전부 찾아다녀야 한다 |

## 세션 시작 점검 (매번)

- `git log --oneline -20`부터 본다 — 여러 툴에서 나눠 작업한다. 내가 만들지 않은
  커밋이 이미 쌓여 있을 수 있다.
- 기준 줄기는 `main` 하나다. 새 작업은 `git fetch origin && git checkout -b <브랜치>
  origin/main`으로 시작한다.
- 지형: `Komjirak/ai-team-kit`. 팀 하네스는 저장소 루트(`TEAM.md`·`docs/`·`.claude/`),
  **제품 소스는 `apps/lectio/` 아래로 분리**한다. 둘을 섞지 않는다.
- 진행 중인 작업 브랜치: **없음** (하네스 개편 브랜치는 main에 병합됨). 새 작업은
  위 방식대로 `main`에서 새 브랜치를 따서 시작한다 — 옛 브랜치를 이어 쓰지 않는다.
