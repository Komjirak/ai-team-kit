# PO 결정 로그

PO가 내린 결정을 번호·날짜와 함께 기록한다. **결정은 여기에만 쌓고, HARNESS에는
요약표만 둔다.** 나중 결정이 이전 결정을 대체하면 지우지 말고 "→ #N으로 대체됨"을
남긴다 — 채록에서 "08-08 지시가 08-05 지시를 대체한다"처럼 이력이 남아야
왜 바뀌었는지 다음 세션이 안다.

형식:

```
## #1 (YYYY-MM-DD) 결정 제목
- 결정: 무엇을 하기로 했나 (한 문장)
- 이유: 왜 (대안과 비교했으면 그것도)
- 영향: 어느 코드/문서/절차가 바뀌나
- 상태: 반영 완료 / 진행 중 / 대기
```
