## 커밋 전 검증

⚠️ **검증은 종료코드로 판정한다 — 출력을 파이프로 자르지 않는다.**

- **앱에 손댔으면**: `cd app && npm run typecheck` (tsc) + `npx expo export`(ios/android/web) 종료코드 0.
- **파이프라인 로직에 손댔으면**: 헤드리스 테스트 러너를 저장소에 커밋해 `npm run verify`로 승격 (QA R-0 — 미커밋 초록불은 없는 것).
- 실기기 육안(고운바탕 한글·마이크·영속화·다크·키보드)은 별도 게이트(QA_CHECKLIST).
