# date.log — Google Stitch 디자인 프롬프트 세트 (반응형 웹 리터칭)

> 사용법: Stitch에서 **[A] 스타일 블록을 먼저 붙여** 톤을 잡고, 이후 각 화면 프롬프트를
> 하나씩 생성한다. 각 화면 프롬프트에도 스타일 요약이 들어 있어 단독으로도 동작한다.
> Stitch는 한국어 프롬프트를 지원하며, UI 텍스트는 아래 한국어 그대로 쓴다.
> (모드는 "Experimental / 웹" 권장. 화면당 1프롬프트가 품질이 좋다.)

---

## [A] 글로벌 스타일 블록 (공통 프리픽스)

```
"date.log"라는 커플 장소 기록 웹앱의 반응형 UI를 디자인해줘. 감성적이고 따뜻한
미니멀 스타일.

무드: 따뜻하고 아늑한 파스텔, 여백이 넉넉하고 둥근 형태. 연인들이 함께 쓰는
다이어리 같은 부드러운 인상.

컬러:
- 배경: 웜 크림/베이지 (#FAF3EC)
- 카드: 화이트 (#FFFFFF), 아주 부드러운 그림자
- 강조/포인트: 코랄 살몬 (#E8846B) — 선택된 탭, 숫자, 날짜, 강조 요소
- 연한 코랄 배경: (#FBE7E0) — 초대코드 박스, 파트너 칩
- 진한 버튼: 에스프레소 브라운 (#4A4038), 흰 글자
- 본문 텍스트: 짙은 브라운 (#2E2A26), 보조 텍스트: 웜 그레이 (#9B9088)

형태: 카드 라운드 16~20px, 버튼은 완전한 pill(알약) 형태, 뱃지도 pill.
타이포: 둥글고 부드러운 산세리프(한국어 Pretendard 느낌), 큰 제목은 볼드.

레이아웃(반응형): 상단에 로고 "date.log"와 슬로건 "우리가 함께 걸은 곳",
우측에 알림 벨 아이콘과 사용자 칩(하트 + "은애 · 파트너 초대 ▾"). 그 아래
가로 필터 칩 바: [전체] [가고싶은 곳] [데이트코스] [추억] [우리의 기록].
선택된 칩은 코랄 배경 + 흰 글자, 나머지는 흰 배경 + 코랄 테두리.
데스크톱은 중앙 정렬 max-width ~1120px, 모바일은 1열로 리플로우.
```

## [1] 온보딩 / 커플 결합

```
[A 스타일 블록] 을 적용해서,

date.log의 온보딩(커플 연결) 화면을 디자인해줘. 화면 중앙에 로고 "date.log"와
슬로건 "우리가 함께 걸은 곳"을 크게 두고, 그 아래 두 개의 큰 pill 버튼을 세로로:
1) 에스프레소 브라운 버튼 "내 초대코드 만들기"
2) 흰 배경 + 코랄 테두리 버튼 "초대코드로 합류하기"
버튼 아래 작은 회색 안내문 "파트너가 합류하면 같은 커플로 연결돼요."
따뜻하고 여백 넉넉하게, 하트나 지도 핀 같은 은은한 일러스트 요소를 배경에.
모바일 우선 반응형.
```

## [2] 가고 싶은 곳 (위시리스트 그리드)

```
[A 스타일 블록] 을 적용해서,

date.log의 "가고 싶은 곳" 목록 화면. 필터 칩 바에서 [가고싶은 곳]이 코랄로 선택됨.
큰 제목 "가고 싶은 곳", 그 아래 회색 소제목 "위시리스트 3곳". 우측 상단에
에스프레소 브라운 pill 버튼 "가고 싶은 곳 추가".

장소 카드 그리드(데스크톱 3열, 태블릿 2열, 모바일 1열). 각 카드:
- 상단에 파스텔 이미지 영역과 좌측 상단 카테고리 뱃지(흰 pill, 예: "카페", "기타")
  카드에 따라 커피 이모지나 빨간 지도핀 이모지 썸네일
- 아래 흰 영역에 볼드 장소명(예: "한남작업실"), 회색 주소(예: "서울 용산구 이태원로55나길 7")
- 하단: 에스프레소 브라운 작은 pill 버튼 "다녀왔어요"와 우측에 회색 텍스트 링크 "수정·삭제 →"

맨 아래 회색 안내 "전환한 장소는 홈 '다녀온 곳' 목록에서 볼 수 있어요."
카드 3개 예시: "사운즈 한남"(기타), "현대카드 뮤직 라이브러리"(기타), "한남작업실"(카페).
```

## [3] 데이트 코스 상세 (지도 + 순서)

```
[A 스타일 블록] 을 적용해서,

date.log의 데이트 코스 상세 화면. 상단 좌측 "← 코스 목록" 링크, 우측에 "수정"과
빨간 "삭제" 텍스트 버튼.

상단 흰 카드: 큰 볼드 코스명 "한남동", 작은 메모 한 줄, 회색 "장소 3곳", 우측에 공유 아이콘.

그 아래 라운드(16px) 지도 영역: 지도 위에 코랄색 선으로 3개 장소 핀을 순서대로
연결한 도보 동선. (데스크톱은 넓게, 모바일은 풀블리드)

아래 "코스 순서" 섹션. 세로 리스트, 각 항목:
- 코랄 원형 번호 뱃지(①②③), 작은 썸네일, 볼드 장소명, 옆에 회색 카테고리 뱃지와
  코랄 "위시리스트" 뱃지, 그 아래 회색 주소
- 항목 사이에 구간 정보 한 줄: "↓ 직선거리 0.17km · 도보 약 3분  [길찾기]"(길찾기는 pill)
예시: ① 한남작업실(카페) → ② 현대카드 뮤직 라이브러리(기타) → ③ 사운즈 한남(기타).
모바일 우선 반응형.
```

## [4] 우리의 기록 (대시보드 · 게이미피케이션)

```
[A 스타일 블록] 을 적용해서,

date.log의 "우리의 기록" 대시보드. 필터 칩 [우리의 기록]이 코랄로 선택됨.
큰 제목 "우리의 기록", 회색 소제목 "숫자로 돌아보는 우리".

1) 상단 넓은 흰 카드(중앙 정렬): 작은 회색 "함께한 지", 볼드 "관계 시작일을 설정해주세요",
   코랄 pill 버튼 "설정에서 입력하기 →".
2) 통계 타일 4개(가로 한 줄, 모바일 2x2): 각 타일에 큰 코랄 숫자와 아래 회색 라벨 —
   "1 다녀온 곳", "3 가고 싶은 곳", "0 남긴 추억", "0 사진".
3) 흰 카드 2개(2열): 왼쪽 "추억이 가장 많은 곳 / 아직 없어요", 오른쪽 "우리의 첫 기록 /
   삼성대주옥  2026.08.31"(장소명 볼드, 날짜 코랄).
4) 하단 흰 카드 "누가 더 많이 등록했을까 🏃", 회색 설명 "러너를 누르면 그 사람이 등록한
   목록을 볼 수 있어요". 그 아래 가로 진행 트랙: 코랄 러너 이모지 🏃 가 달리고 끝에
   체커기 🏁, 우측 아래 "은애 · 4곳". 경쟁이지만 귀엽고 따뜻한 게임 느낌.
모바일 우선 반응형.
```

## 팁 (Stitch 품질 올리기)

- **화면당 1프롬프트.** 여러 화면을 한 번에 요구하면 흐려진다.
- 마음에 든 화면이 나오면 **"이 스타일 유지하고 …만 바꿔줘"**로 이어서 변주.
- 컬러가 안 맞으면 해당 hex를 한 번 더 강조: "포인트 색은 반드시 코랄 #E8846B."
- 영어가 더 잘 나오면 지시문만 영어로 바꾸되 **UI 텍스트(한국어)는 그대로** 두라고 명시.
- 반응형이 약하면 "모바일 375px와 데스크톱 1440px 두 버전을 보여줘"라고 요청.
