### 후보 A — **간직 / 간직.log** (Ganjik) · **1순위 권고**

| 항목 | 내용 |
|---|---|
| 뜻/유래 | **간직하다 = 소중히 지녀 오래 두다.** "이 여행을 간직한다." 제품의 유일한 wedge(BUSINESS_CASE §5 — "여행이 끝난 뒤에도 남긴다")를 **이름 한 단어가 그대로 말한다.** 스크랩북에 눌러 담아 두는 행위와도 정확히 겹친다 |
| 발음/검색성 | "간직" 2음절, 발음 쉬움. **이름으로 등록된 앱이 없다** — "간직"은 여러 앱 태그라인("…간직하는 감성 일기")에만 쓰였을 뿐 브랜드명으론 비어 있어 소유 가능. `.log`를 붙이면 검색 변별력이 더 올라감 |
| 상표/스토어 중복 | 🟢 **낮음.** "간직"이라는 이름의 앱 없음(확인). 인접 감성기록 앱(핀케이션·하루기록·Picto)은 많으나 **이름 충돌은 아님.** 하나카드/Wanderlog와 발음·의미 무관 |
| 도메인/`.log` 적합성 | 🟢 **최상.** "간직.log = 간직하는 기록"으로 **의미가 자연스럽게 읽힌다.** 승계 자산인 `.log` 워드마크 패밀리를 **버리지 않고 계승**하면서 이름만 트래블에서 벗어남. `ganjik.app` / `ganjik.log`(도메인은 GROWTH 확인) |
| 해외 표기 | **Ganjik** / 부제 "keep your trip". 로마자 인지도는 낮으나 국내 20~30대 타깃엔 문제 없음 |
| `.log` 계승 여부 | **계승.** 시각 장치 + 스포큰 네임 둘 다에서 `.log`를 살린다 |
| 남는 우려 | "간직"은 정서가 **조용하다** — 친구끼리 왁자지껄한 여행의 활기보다 "간수/보관"에 가깝다. `.log` 접미사 자체가 포토로그·디로그·트래블로그가 사는 다소 붐비는 접미사 공간이라는 점(단, head가 달라 혼동은 낮음) |

**권고 이유:** 3안 중 유일하게 ① 승계 자산(`.log` 워드마크)을 살리고 ② 제품의 wedge(여행 후 남김·재방문,
K1 리텐션 설계)를 **이름이 직접 인코딩**하며 ③ 이름 소유가 비어 있다. 전략적으로 가장 정합적이다.

### 후보 B — **소풍** (Sopoong) · 근접 2순위(온기·기억성 우위)

| 항목 | 내용 |

| 발음/검색성 | "소풍" 2음절, 누구나 발음. **약점: 일반명사라 SEO가 불리하다**("소풍 앱"으로 검색 유도 필요). 변별력을 로고 락업으로 보완해야 함 |
| 상표/스토어 중복 | 🟡 **중간.** 여행 기억 앱으로 "소풍" 없음(직접 충돌 없음). "소풍의발견"은 체험학습 서비스로 **다른 카테고리**. 단 **소풍벤처스(SOPOONG)**가 위키백과 등재된 유명 임팩트 VC — 소비자 앱과 카테고리는 다르나 "SOPOONG" 로마자 인지도가 겹칠 수 있어 표기·조사 시 유의 |
| 도메인/`.log` 적합성 | 🟡 스탠드얼론 "소풍"이 자연스럽다. `.log`는 스포큰 네임보다 **시각 장치로만** 얹는 게 맞음("소풍로그"는 발음이 다소 어색) |
| 해외 표기 | **Sopoong** / "picnic". 소풍벤처스와 동일 로마자라는 점만 유의 |
| `.log` 계승 여부 | **부분 탈피.** 이름은 `.log`를 버리고, `.log`는 로고의 시각 서명으로만 계승 |
| 남는 우려 | 일반명사 SEO 불리 · SOPOONG(VC) 로마자 중복 · `.log` 워드마크를 이름에서는 못 살림 |

### 후보 C — **끼리 / 우리끼리** (Kkiri) · 3순위(친구 밀착 정서)

| 항목 | 내용 |
|---|---|
| 뜻/유래 | **"친구끼리" = 우리끼리만의.** 타깃(친구끼리 함께 여행 다니는 그룹, BUSINESS_CASE §타깃)을 **이름이 직접 호명**한다. 초대 링크로 닫힌 우리만의 공간이라는 제품 구조와 정확히 맞음 |
| 발음/검색성 | "끼리" 2음절, 경쾌·구어체로 20~30대 친화. 단독 "끼리"는 의미가 **덜 완결**돼 락업 필요 |
| 상표/스토어 중복 | 🟡 **중간.** "끼리"라는 이름의 앱 없음(직접 충돌 없음). 그러나 **인접 경쟁이 가깝다** — "짝꿍(우리들만의 커뮤니티 + 정산)", "포트: 친구끼리 프라이빗 공유"가 친구 그룹+정산 공간을 이미 점유. 이름 충돌은 아니나 **컨셉 근접** |
| 도메인/`.log` 적합성 | 🟡 "끼리.log" 가능하나 의미 결합이 A만큼 자연스럽진 않음 |
| 해외 표기 | **Kkiri** — 로마자 발음 난도 있음(kk-) |
| `.log` 계승 여부 | **탈피 우세.** `.log`는 시각 장치로만 |
| 남는 우려 | 인접 경쟁(짝꿍·포트)이 가까움 · 단독으로 의미 미완결 · 로마자 표기 난도 |

### 세 안이 무엇이 다른가 (PO가 고르는 축)

| | A 간직.log | B 소풍 | C 끼리 |
|---|---|---|---|
| 전략 | **계승** (`.log` 살림) | 탈피 (정서로 비껴감) | 탈피 (친구 호명) |
| 이름이 말하는 것 | 여행 **후** 남김(=wedge) | 가벼운 **나들이**(안티플래너) | **친구끼리** 우리 공간 |
| 승계 자산 활용 | 최상 (`.log` 계승) | 부분(시각만) | 부분(시각만) |
| 변별력/소유가능성 | 높음 | 중(일반명사) | 중(인접 경쟁) |
| 정서 온도 | 조용·차분 | **따뜻·활기** | 경쾌·친밀 |

**BRAND 권고: 1순위 A(간직.log).** 승계 자산을 살리면서 wedge를 이름에 담는 유일한 안이다.
다만 **온기·기억성만 보면 B(소풍)가 더 세다** — PO가 "조용한 전략 정합"보다 "따뜻한 첫인상"을
우선한다면 B가 정답일 수 있다. 이 트레이드오프는 취향이 아니라 **PO의 제품 성격 결정**이라 넘긴다.

## 2. 브랜드 정의 · 성격 · 안티무드

### 한 줄 정의
> **친구와 함께 떠난 여행을, 끝난 뒤에도 꺼내 보는 스크랩북.** 계획과 정산은 가볍게 거들 뿐,
> 우리가 파는 건 **여행이 끝난 자리에 남는 기억**이다.

### 성격 형용사 (4개)
- **다정하다** — 기능이 아니라 사람(친구)을 먼저 본다. 말투가 안내문이 아니라 옆자리 친구다.
- **가볍다** — 계획도 정산도 부담을 지우지 않는다. "해야 하는 앱"이 아니라 "열면 기분 좋은 앱".
- **손때 묻은(handmade)** — 반듯한 디지털이 아니라 washi tape·핀·폴라로이드로 붙인 **손으로 만든 페이지**의 질감.
- **오래가는(keepsake)** — 한 번 쓰고 버리는 도구가 아니라 **두고두고 넘겨보는 물건**. 리텐션(K1)을 정서로 설계한다.

### 안티무드 — 무엇처럼 보이지 않아야 하는가 (이게 이 문서의 심장)
- ❌ **여행 플래너 유틸리티처럼(트리플·Wanderlog).** 촘촘한 일정표·예약 버튼·"최적 경로"의 효율 톤 —
  우리가 정면충돌해서 지는 자리다(BUSINESS_CASE §5). 화면이 **대시보드**처럼 보이면 실패.
- ❌ **핀테크 정산 앱처럼(토스·트래블월렛·Splitwise).** 차가운 숫자·"정산 요청" 알림·금융 UI. 정산은
  넣되 **돈이 주인공이 되면 안 된다** — "너는 나한테 3만 2천 원"은 **친구끼리 툭 던지는 말투**로.
- ❌ **여행 인플루언서 피드처럼(여행에미치다).** 남에게 보여주려는 화보·해시태그·"좋아요". 우리는
  **우리끼리 보는** 닫힌 스크랩북이지, 공개 자랑이 아니다.
- ❌ **감성 과잉 다이어리처럼.** 파스텔 남발·손글씨 폰트 도배·이모지 떡칠. 따뜻하되 **정돈**돼야 한다 —
  Dakku의 절제된 스크랩북이지 다꾸 과열이 아니다.
- ❌ **B2B SaaS처럼.** 회색조·중립·"효율/생산성" 언어. 우리는 도구이기 전에 **추억**이다.

## 3. 톤앤보이스 원형 (PD의 UX 라이팅 · GROWTH의 카피가 여기서 파생된다)

원칙: **옆에 앉은 다정한 친구의 말투.** 존댓말 기반이되 딱딱하지 않게, 명령형("하세요") 대신
청유·서술("~해요/~했어요"). 숫자·정산조차 사람 말로 옮긴다. 이모지는 **문장을 대신하지 않고 거들 때만.**

| 상황 | ❌ 이렇게 말하지 않는다 (안티무드) | ✅ 이렇게 말한다 (원형) |
|---|---|---|
| **초대** | "그룹에 멤버를 초대하세요. 링크가 생성되었습니다." | "카톡으로 링크 하나 보내면 끝! 친구들 다 불러와요." |

## 4. 비주얼 방향 — 승계할 것 / 여행용으로 확장할 것

### 승계 (Datel.log Dakku 스크랩북 — 그대로 계승, PD는 파생)
- **질감:** grid paper(모눈) 배경, washi tape(마스킹테이프) 모서리, pin(핀), polaroid 프레임, 손으로 붙인 콜라주.
- **웜 코랄 팔레트**(아래 §5에서 라이트/다크 한 쌍 + 대비비로 확정).
- **`.log` 워드마크의 시각 서명** — Space Mono로 조판된 소문자 `.log` 태그. 스포큰 네임이 무엇이든
  로고 락업에 이 모노 태그를 유지하면 승계 자산이 살아남는다.

### 확장 — 커플 모티프를 여행 그룹 모티프로 교체 (PD 착수 전 방향 제시)
- ❌ **버릴 것: 하트(♥).** 커플 1:1의 상징이라 친구 N인 그룹엔 안 맞는다. 화면·아이콘에서 하트를 걷어낸다.
- ✅ **여행 스티커 세트(승계한 폴라로이드·washi tape 위에 얹을 모티프 후보):**
  - **여권 스탬프(passport stamp)** — 원형/사각 잉크 도장. "다녀온 자리"를 찍는 은유. 회고 wedge와 정합. **1순위 모티프.**
  - **지도 핀(map pin)** — 승계한 지도 동선과 직결. 장소 담기·동선 페이지의 기본 마크.
  - **티켓 스텁 / 보딩패스 조각** — 스크랩북에 끼워 둔 표. 정산·일정 카드의 데코.
  - **종이비행기** — 초대("친구 부르기") 모션·빈 상태에 가볍게. 남용 금지(감성 과잉 안티무드).
  - **washi tape·폴라로이드·핀** — 승계 그대로 유지, 그룹 사진(여러 명)에 맞게 폴라로이드 다중 배치.
- **모티프 규칙:** 한 화면에 스티커는 **절제**해서(안티무드 "다꾸 과열"). 스탬프·핀을 주역으로, 나머지는 조역.

### 코어 컬러 원형 (PD 디자인 토큰의 **원본** — 라이트/다크 한 쌍, WCAG 대비비 기재)

> 대비비는 sRGB 상대휘도로 계산. **본문 4.5:1 / 큰 텍스트·아이콘 3:1** 기준(brand.md 규칙).
> 핵심: **밝은 코랄 #E8846B는 텍스트 색이 아니다**(대비 부족) — 데코·채움 전용. **텍스트/버튼은 딥 코랄 #984631.**

### 타이포 원형
- **디스플레이/헤드라인(라틴):** **Bricolage Grotesque** — 승계. 특유의 손맛·따뜻함이 스크랩북과 맞음.
- **모노/태그·숫자:** **Space Mono** — `.log` 태그, 타임스탬프, **정산 금액**(고정폭 숫자가 돈 읽기에 유리).
- **본문/한글:** **Pretendard** — 한글 UI 표준. **얇은 웨이트(Thin/Light) 금지**(저대비 가독성 규칙,
  친구 그룹엔 연령 폭도 있음). 본문 최소 15~16px, Regular 이상.
- 조합 원칙: 제목은 Bricolage(라틴)+Pretendard(한글) 병행, 숫자·태그만 Space Mono. 3서체를 넘기지 않는다.

### 앱 아이콘 방향 — **[컨셉, 확정 아님]**
아래는 방향 제시다. 확정 아이콘은 PO 이름 결정 후 PD와 확정한다.
1. **러기지 태그 + 모노 태그** — 여행 가방 수하물 태그(luggage tag) 실루엣 위에 딥 코랄 바탕,
   Space Mono `.log` 각인. 승계 자산(`.log`)을 아이콘이 직접 계승. **간직.log 채택 시 1순위.**
2. **여권 스탬프** — 크림 배경에 딥 코랄 원형 스탬프 마크(핀/비행기 실루엣 음각). "다녀온 자리" 은유.
   이름이 소풍/끼리(탈피)일 때 잘 맞음.
3. **폴라로이드 한 장 + washi tape** — 크림 위 폴라로이드 프레임, 코랄 washi tape 한 조각.
   가장 "스크랩북"다우나 소형 사이즈에서 디테일이 뭉갤 위험 — 대비·단순화 검증 필요.

## 5. PO 결정 대기 항목

1. **[이름 확정]** A 간직.log(권고) / B 소풍 / C 끼리 중 택. 트레이드오프는 §1 마지막 표 —
   "전략 정합·승계(A)"냐 "따뜻한 첫인상(B)"이냐가 핵심 축. **이름이 정해져야 아이콘·도메인·스토어가 딸려 확정된다.**
2. **[대외 확인 지시]** 확정 후보에 대해 **KIPRIS 정식 상표조사 + 스토어 실등록 최종 확인**을 GROWTH에
   지시할지(대외 검색·발송은 PO 승인 영역, TEAM.md §5·9). 이 문서의 웹 검색은 1차 스크리닝이지 법적 조사가 아니다.
3. **[도메인]** 확정 이름의 도메인 확보 여부 확인(GROWTH). `.app`/`.kr` 등.
4. **[아이콘 확정]** §4 컨셉 3안 중 방향 승인 → PD와 최종 제작.
