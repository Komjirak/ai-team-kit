# 경쟁·동향 분석 — 부모 매일질문→자서전(앱인토스 시니어+앱테크)

## 1. 한 줄 결론
"자서전 산출물"을 파는 곳은 국내외에 이미 많지만, **부모가 스스로 리워드(포인트)를 받으며 매일 기록하게 만드는 모델은 아무도 안 하고 있다** — 결제 주체와 획득 동기를 뒤집은 이 지점이 우리의 유일한 빈틈이다.

## 3. 우리의 강점·약점
**강점**
- 결제/동기 구조 반전: 기존은 "자녀가 선물 결제→부모가 생산". 우리는 "부모가 포인트 받으며 자발적 기록". 선물 진입장벽·계절성에서 자유.
- 리텐션 증명된 채널: 앱인토스 3천만 유저, 시니어가 만보기로 이미 매일 진입. 자서전 앱 최대 약점(주1회 알림→방치)을 앱테크 습관이 해결.
- 산출물은 자서전으로 동급인데 획득 경로가 무료·매일·자발적.
- 일본 빈틈: 종활·대필 유료 프레임뿐, 앱테크 리워드 결합 사례 없음.

**약점**
- 수익 모델 불명확(무료+포인트면 회수처가 결국 책 판매=기존 선물 전환에 의존).
- 포인트 비용 지속성(기록 1건 단가 > 전환율이면 적자).
- 산출물 품질(짧은 답 누적 vs 심층 인터뷰).
- 프라이버시·동의(부모 사적 답변→자녀 전달, 공개 범위 설계 필수).
- 앱인토스 내부 주의력 경쟁(만보기 등과 시간 경쟁).

## 4. 대응 제안
1. 차별 메시지를 "선물"이 아니라 "매일 용돈처럼 기록"으로. 자서전은 후행 노출.
2. 진입 완전 무료 유지, 수익은 책 전환에 태움(벤치마크 6~20만원대). 포인트 비용은 전환 LTV 내 상한.
3. 품질 방어: 매일 질문을 자서전 챕터 구조에 매핑, 조각이 자동 목차화. 말하기 입력 기본값.
4. 일본은 종활이 아니라 "매일 앱테크+가족 전달"로 진입. 선점 우선순위 높음.
5. 내부 카니발 방지: "걷기 후 1문항"처럼 동선 연결.
