# 지불 의사(WTP) 인터뷰 패키지 — 하루담 (가제)

작성: **BD** · 2026-09-02 · 상태: **PO 검토 대기 (발송·모집은 PO)**

이 문서 하나를 들고 나가면 인터뷰를 돌릴 수 있게 만들었다. 순서는
**가설 → 리크루팅 → 자녀 가이드(45분) → 부모 가이드(30분) → 가격 측정 도구 →
컨셉 카드 → 분석 프레임 → 가짜 문 랜딩**이다. 판정선은 `BUSINESS_CASE.md` §1의
착수 조건(G1~G3)과 §2의 중단 기준(K1·K2)에 그대로 연결된다.

⚠️ **설문·인터뷰 모집 문안 발송, 랜딩 발행, 사례비 지급은 대외 접촉이다 — PO가
한다.** 이 문서는 초안까지다 (TEAM.md §5).

**원칙 두 가지 (전 섹션 공통)**
1. **Mom Test** — 미래 의향("사시겠어요?")이 아니라 **과거 행동**("작년 어버이날
   뭘 얼마에 사셨어요?")을 묻는다. 칭찬은 데이터가 아니다. 구체적 행동·돈·시간만
   기록한다.
2. **유도 금지** — 컨셉을 보여 주기 전에는 "하루담"을 언급하지 않는다. 질문에
   답이 들어 있으면("매일 안부가 중요하시죠?") 폐기한다.

## 3. 인터뷰 가이드

### 3-1. 자녀용 심층 인터뷰 (45분)

**진행 원칙**: 녹음 동의 먼저. 노트에는 "행동·숫자·인용문"만. 인터뷰어는 30% 이하만
말한다. 침묵 5초를 견딘다. "보통은요?"가 나오면 "가장 최근엔요?"로 되묻는다.

| 시간 | 섹션 | 목적 |
|---|---|---|
| 0~3분 | **오프닝** | 긴장 풀기·동의 |
| 3~12분 | **맥락** — 부모와의 관계·연락·선물의 실제 | 과거 행동 기준선 |
| 12~22분 | **문제** — 부모 이야기·안부에 대해 겪은 것 | H1·H8·H10 |
| 22~32분 | **해결안 반응** — 컨셉 카드 3종 | H3·H9 |
| 32~41분 | **가격** — PSM + Gabor-Granger | H2·H7 |
| 41~45분 | **클로징** | 부모 소개·후속 |

**오프닝 (0~3분)**
- "저는 부모님 세대와 자녀 세대가 어떻게 연락하고 무엇을 선물하는지 배우고 있어요.
  정답은 없고, 실제 있었던 일을 들려주시면 됩니다. 녹음해도 될까요? 이름은 빠집니다."

**맥락 (3~12분)** — 전부 과거형으로
1. "부모님은 어디 사세요? 마지막으로 뵌 게 언제였어요? 그때 뭐 하셨어요?"
2. "부모님과 마지막 통화가 언제였고, 몇 분쯤 하셨어요? 무슨 얘기를 하셨는지 기억나세요?"
3. "부모님이 스마트폰으로 뭘 하세요? 최근에 부모님이 보내신 카톡을 하나 보여 주실 수 있을까요?" (음성메시지·사진·링크 여부 관찰)
4. "작년 어버이날에 뭘 하셨어요? 얼마 쓰셨어요? 그건 어떻게 골랐어요?" → "그 전 해에는요?"
5. "부모님 생신엔요? 형제분들과 어떻게 나눠요?"
6. (S4) "다가오는 행사 준비를 뭐부터 시작하셨어요? 예산은 얼마로 잡으셨어요?"

**문제 (12~22분)**
7. "부모님이 살아온 얘기 중에 '이건 처음 듣네' 했던 게 최근에 있었어요? 언제, 어떤 얘기였어요?"
8. "그런 얘기를 남겨야겠다고 생각한 적 있으세요? **그래서 실제로 뭘 하셨어요?**" (녹음·질문책·메모·가족 인터뷰·아무것도) → 안 했다면 "뭐가 걸렸어요?"
9. (H8) "부모님께 질문하는 책이나, 복지관 자서전 교실 같은 게 있는데 아세요? 해 보셨어요? 어떻게 됐어요?"
10. "부모님 안부가 걱정돼서 뭔가를 바꾼 적이 있어요? (통화 요일 정하기, 안부 앱, 형제 순번…) 얼마나 갔어요?"
11. (H10) "어버이날·생신 말고, 최근에 '엄마/아빠한테 뭐라도 해야겠다' 싶었던 순간이 언제였어요? 뭐 때문이었어요?"
12. (S2) "그 일이 있고 나서 부모님과의 연락이 어떻게 달라졌어요?"

**해결안 반응 (22~32분)** — 컨셉 카드 §6을 **A → C → B 순서로 하나씩** 보여 준다. 카드마다:
13. "이걸 보고 처음 든 생각을 그대로 말씀해 주세요." (5초 침묵)
14. "부모님이 이걸 받으면 첫날 뭐라고 하실 것 같아요? 3일째엔요?"
15. "이 카드에서 **한 줄을 지워야 한다면** 뭘 지우겠어요?" (매일 리포트를 지우면 H3 신호)
16. "이걸 사는 걸 막는 게 있다면요?" (실패 시 무안함·부모 부담·프라이버시·가격 — 순서 기록)
17. 세 카드 모두 본 뒤: "셋 중 하나만 부모님께 드린다면 어떤 거예요? 왜요?" · C 카드에 대해 "부모님이 용돈 때문에 답하시는 걸로 보일까 걱정되세요?" (H9)

**가격 (32~41분)** — §4 도구를 **A 카드 기준**으로. 선물 맥락과 평상시를 분리해 묻는다.
18. Van Westendorp 4문항 (§4-1)
19. Gabor-Granger 사다리 (§4-2) — "어버이날 선물로"와 "지금 당장, 이유 없이"를 각각
20. 책 업셀 (§4-3)
21. "지난 어버이날 쓰신 ○○만 원 중에서 이걸 사면 뭐가 줄어요?" (현금 대체 vs 추가)

**클로징 (41~45분)**
22. "제가 안 물어봤는데 말하고 싶은 게 있으세요?"
23. "부모님과 30분 통화 인터뷰를 해도 괜찮을까요? 부모님께 먼저 여쭤봐 주시겠어요?"
24. "이런 게 나오면 알려 드릴까요? (연락처 — 가짜 문 대체 신호)"

**금지 질문 목록**: "이거 좋으시죠?" · "얼마면 사시겠어요?"(단독) · "매일 안부가
중요하시죠?" · "부모님이 좋아하실 것 같지 않아요?" · 미래 가정형 전부("만약 나온다면").

### 3-2. 부모용 인터뷰 (30분, 대면 또는 전화)

**시니어 배려 원칙**: 대면이면 자녀 동석 여부를 부모가 고른다. 전화면 오후 2~5시.
질문은 짧게, 한 번에 하나. 존칭·이름 호칭은 부모가 정한 대로. 답을 재촉하지
않는다. "테스트"라는 말을 쓰지 않는다 — "이야기 들으러 왔어요".

| 시간 | 섹션 |
|---|---|
| 0~3분 | 인사·동의 (녹음은 반드시 구두 동의 후, 거부 시 메모만) |
| 3~10분 | 자녀와의 연락·스마트폰 사용의 실제 |
| 10~20분 | **시연** — 세 가지 입력 방식으로 질문 1개씩 |
| 20~27분 | 프라이버시·"자녀가 볼 수 있다"·용돈 반응 |
| 27~30분 | 마무리·선물 |

**연락·스마트폰 (3~10분)**
1. "자녀분들이 몇 분이세요? 어디 사세요? 누구랑 제일 자주 통화하세요? 언제 마지막으로요?"
2. "카톡 하실 때 글자로 하세요, 말로 하세요(음성메시지)? 사진은요?"
3. "앱 새로 까는 건 누가 해 줘요?"
4. "살아온 얘기를 자식이나 손주한테 길게 해 본 적 있으세요? 언제요? 뭘 얘기하셨어요?"

**시연 (10~20분)** — 순서를 참가자마다 바꾼다(순서 효과 제거). 각 방식으로 **실제
질문 1개**를 하고, 답변 시간(초)·머뭇거림·표정을 기록한다. 질문은 쉬운 것으로:
"어릴 때 살던 동네는 어떤 곳이었어요?" / "첫 월급 받은 날 기억나세요?" / "첫째 낳던 날 어땠어요?"

| 방식 | 시연 방법 | 관찰 |
|---|---|---|
| ㉠ **전화** | 인터뷰어가 (전화면 그대로, 대면이면 옆방에서) 전화를 걸어 질문 1개 | 답변 길이 · "누구세요" 반응 · 끊김 |
| ㉡ **카톡 음성메시지** | 카톡으로 질문 텍스트+음성 보내고, 음성메시지로 답해 달라 | 스스로 녹음 버튼을 누르는가 · 재생해 확인하는가 |
| ㉢ **앱/웹 화면** | 종이 목업(큰 글씨, 버튼 1개 "말하기") 보여 주고 눌러 보게 | 손가락이 어디로 가는가 · 글자 크기 반응 |

5. 시연 후: "셋 중에 매일 하라면 어떤 게 제일 편하세요? 제일 싫은 건요? 왜요?" (H6)
6. "오늘 질문이 어땠어요? 이런 걸 매일 하나씩 물어보면 며칠이나 하실 것 같아요?" — 그리고 **"지금까지 며칠 이상 매일 해 본 게 뭐예요?"** (만보기·성경 필사·일기·약) 로 과거 행동 확인
7. "질문이 어려웠던 순간이 있었어요?" · "기계 목소리(인터뷰어 목소리)는 어떠셨어요?"

**프라이버시·동기 (20~27분)**
8. "말씀하신 걸 글로 정리해서 자녀분이 매일 저녁 한 줄씩 받아 본다면 어떠세요?" (H5) → 반응 후: "**부모님만 보는 서랍**이 따로 있고, 자녀에게 보여 줄 얘기를 고를 수 있다면요?"
9. "얘기 안 하고 싶은 주제가 있으세요? (자녀가 '피할 이야기'를 미리 적을 수 있다는 걸 알려 준 뒤) 그걸 자녀가 정해 두는 건 어떠세요?"
10. "석 달 뒤에 이 얘기들이 책 한 권이 돼서 오면요? 누구한테 주고 싶으세요?"
11. (H9, C안) "자녀분이 '매일 답하시면 석 달 뒤 용돈 만 원을 드릴게요' 하고 미리 넣어 뒀다면 어떠세요?" — 표정·첫 단어 기록
12. "이 얘기들이 회사 서버에 저장된다는 것, 어떠세요? 지우고 싶으면 지울 수 있다면요?"

**마무리 (27~30분)**
13. "오늘 하신 얘기 중에 자녀분한테 꼭 전하고 싶은 한 가지가 있다면요?" (이 답을 소책자 표지에 넣어 드린다)
14. 감사·사례비·"2주 뒤에 오늘 이야기를 정리한 소책자를 보내 드려도 될까요?" (V0 산출물 품질 G3 측정 기회)

## 4. 가격 측정 도구

### 4-1. Van Westendorp PSM (4문항) — 자녀, A 카드 기준

"방금 보신 서비스(90일, 매일 인터뷰, 자녀 매일 리포트, 전자책 포함)를 **어버이날
선물로** 산다고 할 때" — 각 문항에 금액을 자유 기입:

| # | 문항 | 곡선 |
|---|---|---|
| V1 | 어느 가격부터 "**너무 싸서** 뭔가 부실하겠다" 싶으세요? | Too cheap |
| V2 | 어느 가격이면 "**싸다, 잘 샀다**" 싶으세요? | Cheap |
| V3 | 어느 가격부터 "**비싸지만** 그래도 살 만하다" 싶으세요? | Expensive |
| V4 | 어느 가격부터 "**너무 비싸서** 안 산다" 싶으세요? | Too expensive |

**같은 4문항을 "평상시(이유 없이, 그냥 이번 달에)"로 한 번 더** 묻는다.
분석: 누적 곡선 교점으로 PMC(하한)·PME(상한)·OPP·IPP를 구한다. **판정: 49,000원이
[PMC, PME] 안에 있으면 H2 유지.** 선물 맥락 PME − 평상시 PME 차이가 곧 "시즌
프리미엄"이다 (H10 보조).

### 4-2. Gabor-Granger 사다리 — 자녀

"이 가격이면 사시겠어요?" 를 **아래→위 또는 위→아래를 참가자마다 바꿔서** 묻고, 답은
5점(반드시 산다 / 아마 산다 / 모르겠다 / 아마 안 산다 / 절대 안 산다).

| 단계 | 일회성 (90일) | 구독 대안 |
|---|---|---|
| L1 | **29,000원** | 월 9,900원 |
| L2 | **49,000원** ← 브리프 가격 | 월 14,900원 |
| L3 | **79,000원** | — |
| L4 | **129,000원** | — |

각 단계를 **(a) 어버이날/생신 선물로** · **(b) 평상시** 두 번 묻는다. 그리고
구독 vs 일회성: "같은 내용을 월 9,900원 구독으로 계속하는 것과 49,000원 한 번에
석 달, 어느 쪽이 편하세요? 왜요?" (P1 vs P2 판정).

**판정**: 49,000원 (a)에서 "반드시+아마 산다" **≥ 40%** 면 H2 유지. 수요 곡선
(가격 × 구매의향%)의 **매출 최대점**을 PO 가격 결정 자료로 낸다.

### 4-3. 실물책 업셀 반응 — 자녀 (완주 가정)

"90일이 끝나고 부모님 이야기가 PDF로 왔어요. 하드커버 책(150쪽, 사진 30장)으로도
만들 수 있다면":

| 단계 | 가격 | 추가 질문 |
|---|---|---|
| B1 | 49,000원 | |
| B2 | **79,000원** ← 제안가 | "형제분들 몫으로 추가 1권 39,000원이면 몇 권 사세요?" |
| B3 | 129,000원 | |

**판정**: 79,000원 "반드시+아마 산다" **≥ 40%** 면 H7 유지. 25% 미만이면 기각.
추가로: "책 대신 **부모님 목소리 파일(USB·QR)** 만 39,000원이면요?" (S4 성훈 가설).

## 5. 가짜 문(fake door) 랜딩 실험 — 정량 보강 (발행: PO)

**목적**: 인터뷰 12명의 말이 아니라 **낯선 사람 1,000명의 클릭**으로 H2를 보강한다.
K1(사전예약 < 1.5% → 재정의·중단)의 측정 장치다.

| 항목 | 설계 |
|---|---|
| 페이지 | 1장. 상단: 보도자료 문단(BUSINESS_CASE §0)을 카피로. 중단: "어떻게 되나요" 3단계(자녀가 신청 → 부모가 매일 답 → 90일 뒤 책). 하단: **가격 버튼** |
| 가격 A/B (트래픽 50:50) | **A: 49,000원 "어버이날/생신 선물로 예약하기"** · **B: 79,000원 (책 포함)** — 클릭률 차이로 가격 탄력을 본다. 세 번째 셀 여유가 있으면 29,000원 |
| 버튼 클릭 후 | "곧 시작합니다. 먼저 알려 드릴게요" + **연락처(카톡 ID 또는 휴대폰) 입력** + 선택 문항 1개: "부모님 연세" · "언제 필요하세요? (어버이날 / 생신 / 지금 바로 / 그냥 관심)" → H10 정량 |
| 정직성 | 결제는 받지 않는다. "사전 예약"임을 버튼 아래 한 줄로 명시. 수집한 연락처는 출시 알림 외 사용 금지·요청 시 삭제 (개인정보 처리 안내 1줄) |
| 트래픽 | 목표 **방문 1,000+ / 2주**. 채널: PO SNS·맘카페·직장인 커뮤니티 글(유료 광고는 소액 10만 원 이내로 CPC 감만 잡는다) |
| 측정 지표 | ① 방문→가격 버튼 클릭률 ② 클릭→연락처 입력률 ③ **방문→사전예약(=②의 분자/①의 분모)** ④ 셀별 차이 ⑤ "언제 필요" 분포 ⑥ 유료 유입의 CPC (CAC 추정용, BUSINESS_CASE R8) |
| **판정** | 사전예약 **≥ 3%** → G1 충족 신호 · **1.5~3%** → 카피·가격 1회 수정 후 재측정 · **< 1.5%** → K1 |
| 확인 사항 | 도메인·랜딩 이름은 **"하루담" 상표 확인(BUSINESS_CASE R6) 전에는 가칭**으로. 발행·광고 집행·연락처 보관은 PO |

## 6. 컨셉 카드 (인터뷰이에게 보여 줄 한 페이지)

**공통 헤더 (세 카드 모두)**
> **"더 늦기 전에 물어보세요."**
> 부모님이 매일 저녁 짧은 인터뷰에 **말로** 답하시면, 그 이야기가 정리되어 90일 뒤
> 한 권의 책이 됩니다. 부모님은 앱을 배우실 필요가 없습니다.

### 카드 A — 자녀 선물형
```
[하루담 · 부모님 이야기 90일]                      49,000원 (1회)

① 당신이 신청합니다 — 부모님 성함, 듣고 싶은 이야기 5가지, 피해 주길 바라는 주제.
② 부모님께 매일 저녁 7시, "오늘의 이야기" 질문이 카톡(또는 전화)으로 갑니다.
   부모님은 말로 답하십니다. 3분이면 됩니다.
③ 당신에게 매일 밤 한 줄이 옵니다 — "오늘 어머니는 첫 직장 이야기를 하셨어요."
④ 90일 뒤, 부모님의 이야기가 전자책이 되어 두 분께 갑니다. (하드커버 책은 별도)
```

### 카드 B — 부모 무료 시작형 (앱테크)
```
[오늘의 한 이야기]                                   무료 · 포인트 적립

① 부모님이 토스(앱인토스) 안에서 "오늘의 질문"에 말로 답하시면 매일 50포인트.
② 답이 쌓이면 자동으로 챕터가 됩니다. 자녀에게 공유할 수 있습니다.
③ 책으로 만들고 싶을 때 자녀 또는 본인이 결제합니다. (책 79,000원)
```

### 카드 C — 하이브리드 "효도 에스크로"
```
[하루담 · 부모님 이야기 90일 + 응원 용돈]           49,000원 (1회)

카드 A와 같습니다. 다만 —
① 49,000원 중 10,000원은 "완주 용돈"으로 미리 넣어 둡니다.
② 부모님이 90일 중 60일 이상 답하시면, 그 용돈이 당신의 이름으로 부모님께 갑니다.
③ 중간중간 당신이 응원 메시지를 남기면 다음 인터뷰 앞에 부모님께 읽어 드립니다.
```

**보여 주는 순서**: 자녀 = A → C → B. 부모 = A(시연 후) → C. 부모에게 B는 보여 주지
않는다(부모가 결제·앱 구조를 판단할 대상이 아님). 카드는 A4 한 장, 본문 16pt 이상,
부모용은 20pt.
